## Method and dataset

The public sample has 32 cases; the evaluation input has 518. The program uses identity snapshots and history, 4,011 activity rows, 15 policy rules, and 94 manifested evidence files. Each sample prediction is generated by the same `audit` function as the final CSV. Exact step precision and recall compare all step fields except `step_no` as a multiset; position-aligned metrics compare rows at the same array index.

## Failures and improvements

The first parser missed handover rows, trace-linked log events, SQL JSON payloads, PDF attachments, and screenshots. The implementation now parses those formats, caches OCR text from participant-facing images, recovers historical identifiers, and filters evidence by audit time. A later participant catalog link now connects artifact IDs to subjects while the artifact itself establishes state. This resolved four formerly unproven COMPLETE cases. Stricter citation-state validation also exposed a wrong policy category for a catalog-linked tombstone; that mapping was repaired and regression-tested. Public-sample status accuracy is 32/32. Exact step arrays still differ in 17 cases, chiefly because compliant absent, anonymized, and retained records can lack an explicit subject identifier in the parsed evidence. 0 full-run COMPLETE rows have no verification step. The engine does not substitute workflow operation results for proof.

Strict validation: **PASS**, 0 mandatory errors. The machine-readable details are in `evaluation/validation_report.json`. CSV shape, ordering, operation/state pairs, cited evidence timestamps, resource membership, and cited observable states were checked. Structural validity does not establish substantive correctness, especially for the conflicting `case_63` identity association documented in `evaluation/four_case_trace.md`.

## Reproduction

Run `python3 code/main.py`, `python3 -m unittest discover -s code/tests`, `python3 code/evaluation/main.py`, then `python3 code/evaluation/validate.py` from the repository root. The last command exits nonzero if mandatory validation errors exist.
